# Γεωμετρίες

Απλοποιημένα αντίγραφα για τον χάρτη. Δεν είναι μετρήσεις.

- `world-countries.json`: Natural Earth 1:110m cultural vectors, public domain.
  https://www.naturalearthdata.com/ — το id είναι `ISO_A3_EH`.
- `greek-regions.json`: NUTS 2024 επίπεδο 2, κλίμακα 1:20m, μόνο κωδικοί EL.
  Πηγή: European Commission, Eurostat / GISCO. Ελεύθερη επαναχρησιμοποίηση με αναφορά πηγής.
- `region-links.json`: ρητά ζεύγη entity id → geometry id. Τα labels δεν ταιριάζουν αυτόματα.
  Η συνθετική περιφέρεια `region:CENTRAL` δεν έχει επίσημο πολύγωνο και δεν ζωγραφίζεται πάνω σε άλλη.
