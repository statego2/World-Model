# Κατάσταση και handoff

Η τρέχουσα κατάσταση συντηρείται στα root αρχεία μνήμης:

- [PROJECT.md](../PROJECT.md): πραγματικό scope και αποφάσεις.
- [ARCHITECTURE.md](../ARCHITECTURE.md): κώδικας και αρχιτεκτονική.
- [PROGRESS.md](../PROGRESS.md): ολοκληρωμένες αλλαγές, έλεγχοι και handoff.
- [TASKS.md](../TASKS.md): τρέχουσα ουρά εργασιών.
